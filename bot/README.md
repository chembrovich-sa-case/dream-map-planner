# 🤖 Телеграм-бот «Горизонт» (Dream Map Planner Bot)

Асинхронный мобильный ассистент для проекта **«Горизонт»**, разработанный на базе современного фреймворка **`aiogram 3`** и взаимодействующий с бэкендом **FastAPI** через защищенный REST API (JWT Bearer).

Позволяет в любой момент прямо из Telegram контролировать баланс сфер жизни, индекс гармонии, отслеживать прогресс целей и оперативно добавлять новые желания в систему.

---

## 🌟 Основные возможности

* 🔑 **Бесшовная привязка аккаунта:** Авторизация под существующей учетной записью резидента системы (`admin` или `user`) с сохранением сессии и JWT-токена.
* 📊 **Команда `/status`:**
  * Текущий **индекс гармоничности** колеса баланса (`0–100%`) с графическим прогресс-баром и вердиктом;
  * Сводка по всем **сферам жизни** (текущий балл из 10, процент реализации, цветовой индикатор);
  * Статистика целей (всего, в работе, достигнуто);
  * **Мультивалютный финансовый срез** запланированных целей в белорусских рублях (**Br / BYN**) и долларах США (**USD**) с пересчетом по официальному курсу Нацбанка РБ (НБРБ).
* 🎯 **Команда `/goals`:** Список активных целей с дедлайнами, прогрессом и суммами.
* ➕ **Команда `/newgoal`:** Пошаговое добавление цели прямо в чате через диалоговую машину состояний (FSM: Название → Сфера → Бюджет).
* 🛡 **Отказоустойчивость:** Автоматическая диагностика доступности сервера FastAPI, дружелюбные сообщения об ошибках сети и подсказки по запуску локального бэкенда.

## ⚡ Быстрый старт и запуск

### Шаг 1: Получение токена бота

1. Откройте приложение Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям:
   - Введите имя бота (например: `Horizont Planner Bot`);
   - Введите юзернейм бота, оканчивающийся на `bot` (например: `horizont_planner_bot`).
3. Скопируйте выданный API-токен (вида `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`).

---

### Шаг 2: Настройка виртуального окружения

В терминале перейдите в папку `bot/`:

```powershell
cd d:\Antigravity\Horizont\bot

# Создание виртуального окружения Python
python -m venv venv

# Активация на Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# Либо на Windows (CMD):
venv\Scripts\activate.bat

# На Linux / macOS:
source venv/bin/activate
```

---

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

---

### Шаг 4: Настройка переменных окружения (`.env`)

Создайте файл `bot/.env` на основе примера `bot/.env.example`:

```env
# Токен вашего бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Базовый адрес работающего FastAPI бэкенда
API_BASE_URL=http://127.0.0.1:8000/api

# Таймаут запросов (сек)
REQUEST_TIMEOUT=8.0
```

---

### Шаг 5: Запуск бота

Перед запуском бота убедитесь, что бэкенд FastAPI запущен в соседнем терминале:

```powershell
# В первом терминале (папка backend):
uvicorn main:app --reload

# Во втором терминале (папка bot):
python main.py
```

После успешного запуска в консоли появится подтверждение:


## 🎮 Доступные команды в Telegram

| Команда | Назначение |
|---|---|
| `/start` | Приветствие, проверка авторизации, 1-click демо-вход |
| `/login <логин> <пароль>` | Авторизация в системе под своим аккаунтом |
| `/status` | **Сводка баланса жизни:** Индекс гармонии %, баллы сфер, бюджеты в Br и USD |
| `/goals` | Реестр активных целей, прогресс, статус и дедлайны |
| `/newgoal` | Интерактивное пошаговое создание новой цели прямо из чата |
| `/help` | Полная справка по возможностям и ссылка на веб-версию |
| `/logout` | Сброс привязки аккаунта и удаление токена |
| `/cancel` | Отмена текущего диалога ввода (при создании цели или логине) |

## 🛡 Обработка ошибок

* **Бэкенд недоступен:** Бот сообщает пользователю, что сервер FastAPI временно недоступен по адресу `http://127.0.0.1:8000`, и предлагает запустить его через `uvicorn main:app --reload`.
* **Истек JWT-токен:** При получении `401 Unauthorized` бот автоматически сбрасывает устаревшую сессию и предлагает повторно пройти авторизацию через удобную кнопку в чате.
