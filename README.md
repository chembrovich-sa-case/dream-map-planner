# 🌟 Проект «Горизонт» (Dream Map Planner)

> Современное интерактивное веб-приложение для визуализации жизненных целей (Карта желаний / Vision Board) и мониторинга баланса по сферам жизни на радарной диаграмме с ролевой моделью доступа (RBAC) и панелью CMS.

![Горизонт](src/assets/logo.svg)

---

## 🎯 Основные возможности

1. **Интерактивная карта желаний (Vision Board):**
   * Витрина карточек целей с сортировкой, фильтрацией по сферам и дедлайнам.
   * Декомпозиция целей на пошаговые контрольные этапы (чек-лист шагов с весами).
   * Автоматический расчет прогресса цели (0–100%) в реальном времени.

2. **Радарная диаграмма баланса (Колесо жизненного баланса):**
   * Интерактивная радарная диаграмма на базе `Chart.js` с поддержкой светлой и темной темы.
   * Сводный индекс баланса системы (0–10) и расчет отклонений от целевых ориентиров.
   * Мониторинг по 6 ключевым сферам: Карьера и Бизнес, Финансы, Здоровье и Спорт, Саморазвитие, Отношения и Семья, Отдых и Впечатления.

3. **Мультивалютность и официальный курс Нацбанка РБ (НБРБ):**
   * Поддержка отображения финансовых целей в **BYN** (белорусский рубль) и **USD** (доллар США).
   * Автоматическое кэширование официального курса API НБРБ (`api.nbrb.by`) один раз в сутки в `localStorage`.

4. **Встроенная панель администрирования (CMS):**
   * Управление справочником сфер жизни (добавление, редактирование цветов и целевых баллов).
   * Табличный реестр целей с массовым управлением статусами (`draft`, `in_progress`, `achieved`, `archived`).
   * Инструменты резервного копирования: экспорт/импорт базы данных в JSON и генерация SQL-скрипта миграций.

5. **Безопасность и ролевая модель доступа (RBAC):**
   * Роли пользователей: `admin` (полный доступ к CMS и дашборду), `user` (витрина целей и радар, CMS скрыта и защищена), `guest` (режим просмотра).
   * Интерактивное модальное окно авторизации и мгновенное переключение демо-профилей.

6. **Системный анализ и документация:**
   * Спецификация требований и Use Cases: [`docs/requirements/vision_and_use_cases.md`](docs/requirements/vision_and_use_cases.md).
   * Спецификация REST API в формате OpenAPI 3.0: [`docs/api/openapi.yaml`](docs/api/openapi.yaml).
   * Реляционная схема PostgreSQL в 3NF с триггерами и представлениями: [`database/schema.sql`](database/schema.sql).
   * Концептуальная диаграмма сущностей Draw.io: [`docs/diagrams/er_concept.drawio`](docs/diagrams/er_concept.drawio).

## 🚀 Быстрый запуск

Приложение не требует установки Node.js, Python или веб-серверов. Все зависимости (Tailwind CSS, Lucide Icons, Chart.js) подключены через CDN, а логика построена на чистом ES6+ JavaScript.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<username>/horizont.git
   ```
2. Откройте файл `src/index.html` напрямую в любом современном веб-браузере (двойной клик или перетаскивание в окно браузера).
